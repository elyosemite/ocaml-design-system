Tokens

Um token é o nome de uma decisão de design. O botão não pede #2563EB: pede o fundo da marca. Quando a marca, o tema ou o contraste mudam, o valor muda num lugar só e a tela inteira acompanha.

O que são tokens

Variáveis CSS com nome e significado, guardadas em dist/tokens.css. Cada uma responde a uma pergunta de design: que cor tem o texto de apoio, quanto espaço separa dois campos, que sombra tem um menu.

Três níveis
Os primitivos são a paleta e as escalas brutas, e só o próprio sistema os usa. Os semânticos dizem a intenção e são o que componentes e telas usam. Os de componente ajustam uma peça só, como o fundo de cada variante do botão.
Uma fonte
Os tokens são escritos em Sass, uma pasta por nível e um arquivo por assunto, e viram custom properties no CSS gerado. Quem usa o sistema só precisa do CSS.
Nada de valor solto
Cor, espaço, raio, sombra, fonte, opacidade e tempo sempre passam por um token. A conferência do sistema avisa quando aparece um valor fixo.

O que são temas

Um tema é um conjunto de valores para os mesmos tokens. O nome fica, o valor troca. Use o botão de tema no topo da página e veja os valores abaixo mudarem.

  • --color-textTexto padrão
  • --color-surfaceSuperfície padrão
  • --color-bg-brand-boldFundo do botão principal
  • --shadow-overlaySombra de menus e modais
Claro e escuro
Cada token de cor traz os dois valores lado a lado. O escuro segue o sistema operacional, a menos que a pessoa escolha um tema.
Alto contraste
Não cria cores novas: aponta os tokens de apoio para os mais fortes. Bordas sobem, o texto de apoio vira texto comum e o anel de foco engrossa.
Além da cor
Com "reduzir movimento" ligado no sistema, os tokens de duração vão a zero. A densidade troca as alturas de linha e de controle.

Por que usar tokens

Temas de graça
Uma tela feita só com tokens funciona no claro, no escuro e no alto contraste sem nenhuma linha a mais.
Uma mudança, todo lugar
Mudar o raio dos botões ou o azul da marca é editar um arquivo. Não existe caça a valores espalhados.
Mesma língua
Design e código falam "fundo de perigo forte", não "aquele vermelho". A conversa e a revisão ficam mais curtas.
Conferido
A conferência automática acusa token inexistente, tema sem valor e valor fixo onde havia um token.

Como ler o nome de um token

O nome se lê da esquerda para a direita, do geral para o específico: a fundação, a propriedade e, quando precisa, os modificadores.

-- colorfundação - bgpropriedade - dangerpapel - boldênfase - hoveredestado

Lê-se: a cor do fundo de algo perigoso, forte, com o ponteiro em cima. É o fundo do botão "Excluir" no hover.

Fundação
O tipo de decisão: color, shadow, opacity, space, font, radius, duration. Toda token começa por uma.
Propriedade
Onde a decisão se aplica: text, icon, border, bg (fundo), surface, label, link. Nas escalas (espaço, raio) o lugar está no nome da fundação e a propriedade não aparece.
Modificador
O detalhe que falta: o papel (danger, success, brand), a ênfase (subtle, bold), o estado (hovered, pressed) ou a cor de uma etiqueta (blue). É opcional: --color-text não tem nenhum.

Os modificadores, em um lugar

Papel
brand, information, success, warning, danger, discovery, neutral, selected, disabled, inverse, input.
Ênfase
Do mais leve ao mais forte: subtlest, subtle, o padrão (sem modificador) e bold.
Estado
hovered com o ponteiro em cima, pressed no clique, focused no foco do teclado.
Cor de etiqueta
blue, teal, green, purple, magenta, orange, cada uma com um par bg e text.

Encontrar e usar tokens

Escolha pelo significado, nunca pelo valor. O catálogo completo, com busca e o valor de cada token no tema atual, está em Variáveis CSS.

Faça

  • Escolha o token cujo nome descreve o seu caso: texto de apoio é --color-text-subtle.
  • Use o par certo: fundo bold pede texto inverse.
  • Confira a tela no escuro e no alto contraste antes de entregar.

Não faça

  • Não escolha um token só porque a cor parece certa: no outro tema ela pode sumir.
  • Não use a paleta (--palette-*) direto: ela não troca com o tema.
  • Não escreva valores soltos nem crie um token novo sem passar pela revisão.

Tokens de elevação

A elevação diz o quanto algo flutua acima do resto. Cada nível tem uma superfície e, a partir do elevado, uma sombra. No escuro a superfície clareia em vez de a sombra escurecer.

Tokens de opacidade

Só cinco níveis, cada um com um uso. Nenhum componente usa um número solto.

Tokens de espaço

Base 8, com meios-passos de 2 e 4. O número no nome é o valor em centésimos de rem: 100 é 8px, 200 é 16px.

  • --space-0504px · ícone e texto
  • --space-1008px · itens de uma linha
  • --space-15012px · campos de um formulário
  • --space-20016px · respiro de um card
  • --space-30024px · grupos dentro de uma tela
  • --space-50040px · seções de uma página
  • --space-80064px · respiro entre blocos grandes

Raio, borda e movimento

Raio
Cresce com o tamanho da peça: --radius-small em botões e campos, --radius-medium em menus, --radius-large em modais, --radius-round em avatares.
Borda
--border-width para linhas e caixas, --border-width-focused para o anel de foco.
Movimento
Três durações, --duration-fast, --duration-medium e --duration-slow, e a curva --easing-standard para algo que entra na tela. Com "reduzir movimento", as durações vão a zero.
